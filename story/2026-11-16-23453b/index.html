Apple tests limited face unlock for iPhone Duo via camera

2026-11-16 · 4 outlets · partial

Apple is testing a software-based face-unlock feature for the current iPhone Duo in the iOS 27.3 beta, using the front camera rather than dedicated Face ID hardware, which outlets note falls short of true Face ID security. Separately, leaked prototypes suggest the next-generation Duo 2 could gain full Face ID and other features by 2027.
