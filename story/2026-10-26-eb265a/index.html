Microsoft patches critical Brotli flaw as hackers begin exploiting it

2026-10-26 · 2 outlets · full

Microsoft issued emergency .NET patches for a critical vulnerability in the Brotli compression library, variously tracked as Broccoli2Shell, Node2Shell and HTTP2Shell, which could let attackers corrupt memory and access sensitive data. Other software makers raced to patch the same flaw. Days later, the US Cybersecurity and Infrastructure Security Agency confirmed hackers had begun exploiting it.
